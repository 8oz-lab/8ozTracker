Über 8oz Tracker

8oz Tracker zeigt, welche Spieler der EUW-Flex-Spitze gerade in einem League-of-Legends-Spiel sind. Es ist ein Community-Projekt für Spieler, die die Flex-Ladder verfolgen.

Woher die Daten kommen

Alle Daten stammen aus der offiziellen Riot Games API. Die Ladder (Challenger, Grandmaster, Master der EUW-Flex-Queue) wird regelmäßig neu geladen, der Live-Status der Spieler laufend im Hintergrund geprüft. Wegen der Abfragelimits der API kann ein Status um einige Minuten verzögert sein.

Was gespeichert wird

Die Seite speichert keine Nutzerdaten und setzt keine Cookies. Angezeigt werden nur öffentliche Spielerdaten aus der Riot API.
